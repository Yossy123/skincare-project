# Skincare Project

Repository ini dibagi menjadi 2 branch terpisah:

## 🌿 Branches

- **Frontend**: [Branch `frontend`](https://github.com/Yossy123/skincare-project/tree/frontend)
  - Stack: Next.js (App Router), TypeScript, Tailwind CSS
  - Source code frontend berada di root directory pada branch `frontend`.

- **Backend**: [Branch `backend`](https://github.com/Yossy123/skincare-project/tree/backend)
  - Stack: Laravel, MySQL, Redis, Midtrans, Biteship
  - Source code backend API berada di root directory pada branch `backend`.

---

## 🚀 Cloning Repository

### Clone Frontend Saja:
```bash
git clone -b frontend https://github.com/Yossy123/skincare-project.git frontend
```

### Clone Backend Saja:
```bash
git clone -b backend https://github.com/Yossy123/skincare-project.git backend
```
